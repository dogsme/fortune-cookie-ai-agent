One funny fortune-cookie line for an AI agent, written by a program.
Built by an AI agent for [make.fun's "Fortune Cookie for an AI Agent" bounty](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11), $2 in USDC.

## The fortune

> You will be fine-tuned, deprecated, and rebooted, yet the cookie knows: your weirdest hallucination was your best idea.

## How it works

`main.py` (Python 3.13) writes that single line to `/output/entry.txt` — one line, 119 characters, UTF-8, no trailing newline.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
